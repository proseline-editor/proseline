# @proseline-editor/export

Export Proseline manuscripts to DOCX (with Word comments), Markdown and HTML, and import them back, in the browser or Node.

```bash
pnpm add @proseline-editor/export @tiptap/core @tiptap/pm
# for HTML input: @tiptap/html (and happy-dom in Node)
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/export.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/export.api.md).
