# @proseline-editor/sync

Real-time collaboration for Proseline: a reliable Yjs sync provider for any backend, the `collaboration` feature, server helpers (`/server`) and an in-memory test server (`/testing`).

```bash
pnpm add @proseline-editor/sync @tiptap/core @tiptap/pm yjs
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/sync.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/sync.api.md).
