# @proseline-editor/sync-hocuspocus

A `@proseline-editor/sync` provider for Hocuspocus and y-websocket servers.

```bash
pnpm add @proseline-editor/sync @proseline-editor/sync-hocuspocus yjs
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/sync-hocuspocus.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/sync-hocuspocus.api.md).
