# @proseline-editor/core

Headless core of Proseline, the long-form prose editor: the editor, the prose schema and every feature (typography, paragraph styles, find & replace, stats and goals, focus modes, comments, versions, mentions, style analysis).

```bash
pnpm add @proseline-editor/core @tiptap/core @tiptap/pm
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/core.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/core.api.md).
