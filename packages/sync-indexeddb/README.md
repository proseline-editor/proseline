# @proseline-editor/sync-indexeddb

IndexedDB persistence for `@proseline-editor/sync`: documents open offline and unsent edits survive crashes.

```bash
pnpm add @proseline-editor/sync @proseline-editor/sync-indexeddb
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/sync-indexeddb.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/sync-indexeddb.api.md).
