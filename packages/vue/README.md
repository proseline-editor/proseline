# @proseline-editor/vue

Vue 3 components for Proseline: the same set as the React package, `useController()`, and `theme.css`.

```bash
pnpm add @proseline-editor/core @proseline-editor/vue @tiptap/core @tiptap/pm vue
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/vue.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/vue.api.md).
