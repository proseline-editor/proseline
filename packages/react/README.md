# @proseline-editor/react

React components for Proseline: `<ProselineEditor>`, the toolbar and panels, `useController()`, and `theme.css`.

```bash
pnpm add @proseline-editor/core @proseline-editor/react @tiptap/core @tiptap/pm @tiptap/react
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/react.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/react.api.md).
