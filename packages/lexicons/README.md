# @proseline-editor/lexicons

English, Ukrainian and French word lists for the Proseline style analysis (`/en`, `/uk`, `/fr`).

```bash
pnpm add @proseline-editor/core @proseline-editor/lexicons
```

Documentation, guides and examples: [github.com/proseline-editor/proseline](https://github.com/proseline-editor/proseline#readme).
The public API of this package is listed in [`api/lexicons.api.md`](https://github.com/proseline-editor/proseline/blob/main/api/lexicons.api.md).
